# Dock Scheduler

A reservation system for a marine research facility's waterfront: berths of different lengths, vessels and events that occupy them for day ranges, and a rules engine that answers the two questions the facility used to answer by staring at a spreadsheet grid: *is this berth double-booked?* and *does this vessel fit here?*

Built as a take-home project for Columbia Software Solutions. The plan, every decision and its reason, and the study of the 23-year sample workbook are in [FRAMEWORK.md](FRAMEWORK.md).

## Status

Planning complete; implementation starts with Phase 0 of the framework. This README will gain a quickstart, the headline audit numbers, screenshots and a demo link as the phases land.
