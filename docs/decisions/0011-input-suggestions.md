# 0011 — Suggestions for every typed field

20 September 2026. Add a small native select beside every text, search, date, month, number and multiline input. Native menus provide keyboard and mobile selection without a custom combobox framework. Vessel suggestions use the live registry (up to the API limit of 1,000 matches); Audit suggests only names present in its fixed evidence. Typing narrows name lists and remains available for custom values. Dates retain calendar controls and offer explicit shortcuts, with inclusive stay lengths. Measurements offer only the selected vessel’s recorded value or unknown, never generic guesses. Notes and review reasons append templates and require users to replace bracketed prompts before submitting. Selecting a choice emits the same input/change events as typing, so existing invalidation and server checks remain authoritative; selecting alone never saves. Slow lookups cannot overwrite newer queries, and errors leave typing available with a visible retry message. No dependencies or server-rule changes.
